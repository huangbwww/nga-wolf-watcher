# Issue #27 CSV 导出验收

## 启动测试版

1. 完全退出旧版 NGA Wolf Watcher，包括系统托盘中的程序。
2. 将测试版 `windows-x86_64-portable.zip` 解压到一个新目录，双击其中的 `NGA-Wolf-Watcher.exe`。请先解压完整目录，再运行程序。
3. 确认界面版本为 `v1.6.2-issue27.1`。
4. 打开股票看板。便携版沿用 `%LOCALAPPDATA%\NGA Wolf Watcher` 下的配置和股票列表，不需要重新配置 Cookie 或消息通道。

## 验收项目

| 项目 | 操作 | 预期结果 |
| --- | --- | --- |
| 选择保存位置 | 在股票看板点击「导出」 | 出现系统「另存为」窗口，默认名称为 `策略备份.csv` |
| 自定义目录和名称 | 选择一个中文目录，将文件名改为 `我的策略备份.csv` 并保存 | 看板提示 `CSV 已保存至：`，后面是所选文件的完整路径；资源管理器中能找到该文件 |
| 路径显示 | 缩小窗口，选中提示文字并复制 | 长路径可以换行，文件名完整可见，路径可复制 |
| 文件内容 | 用 Excel 或文本编辑器打开 CSV | 中文列名、股票名称、代码、持仓备注正常显示；行数与股票列表一致（另含一行表头） |
| 取消 | 再次点击「导出」，在保存窗口点击「取消」 | 提示 `已取消导出 CSV`，不出现成功提示，不生成新文件，导出按钮恢复可用 |
| 覆盖 | 再次导出到刚才的测试文件，确认系统的覆盖提示 | 文件更新成功，界面显示实际保存路径 |
| 文件占用（可选） | 在 Excel 中保持测试 CSV 打开，再导出覆盖它 | 如果 Excel 锁定了文件，界面显示导出失败，原 CSV 保持完整；关闭 Excel 后可重试成功 |

股票看板的 CSV 导出包含整个股票列表，不只包含当前筛选或分组中的股票。空列表导出包含表头。
