# v1.6.2

## 中文

修复 [Issue #27](https://github.com/huangbwww/nga-wolf-watcher/issues/27)：股票看板点击导出后提示完成，却找不到 CSV 文件。

旧版通过内嵌浏览器触发下载，但桌面端默认禁用下载；界面的完成提示也没有等待文件真正保存。

- 点击「导出」后弹出系统「另存为」窗口，默认文件名为 `策略备份.csv`，可以选择保存位置和名称。
- 由应用直接写入 CSV，保存成功后显示可复制的完整路径，长路径可以换行。
- 取消保存时提示已取消；保存失败时显示错误，并保留已有备份。
- 保留 UTF-8 BOM 和正确的 CSV 换行、引号处理，兼容中文内容和 Excel。
- 补充 14 项导出回归测试；全量 232 项 Python 测试和前端构建通过，Windows 测试版已实机确认可以弹出保存窗口并保存文件。

升级前请完全退出旧版（包括系统托盘），安装或解压新版后确认界面版本为 `v1.6.2`。便携版沿用现有配置和股票列表。

本 Release 提供 Windows 安装包和便携包、Linux CLI 包，以及 macOS 实验包。CSV 修复针对桌面股票看板。

## English

Fixes [Issue #27](https://github.com/huangbwww/nga-wolf-watcher/issues/27): the stock dashboard reported a completed CSV export even when no file was saved.

The previous implementation triggered a browser download while downloads were disabled in the desktop webview, and reported success without confirming a saved file.

- Export now opens the system **Save As** dialog with `策略备份.csv` as the default filename.
- The app writes the CSV directly and displays its full, selectable path only after saving succeeds. Long paths wrap.
- Cancellation is reported separately from success. Failed writes display an error and preserve existing backups.
- UTF-8 BOM, CSV newlines, and quoting are preserved for Chinese text and Excel compatibility.
- Added 14 export regression cases. All 232 Python tests and the frontend build passed; the Windows preview was manually verified to open the save dialog and save the file.

Fully quit the old app, including its tray icon, before upgrading. Confirm that the new app shows `v1.6.2`. The portable build uses your existing settings and watchlist.

Assets include the Windows installer and portable archive, Linux CLI archives, and experimental macOS packages. The CSV fix applies to the desktop stock dashboard.
