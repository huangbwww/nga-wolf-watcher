# v1.6.1

## 中文

本版本为本地 Codex AI 分析新增 GPT-6 Astra 可选模型，不自动切换用户当前使用的模型。

- 在 AI 分析的 Codex 模型列表中新增 `GPT-6 Astra`（`gpt-6-astra`）。
- GPT-6 Astra 支持选择 `low`、`medium`、`high`、`xhigh`、`max`、`ultra` 推理强度，并将所选模型和强度传递给新任务及续聊任务。
- 保留已有 AI 服务商、模型及推理强度配置；Codex 默认模型仍为 `gpt-5.6-sol`，默认推理强度仍为 `high`。需要用户手动选择并保存才会切换至 GPT-6 Astra。
- 补充模型配置、命令参数、界面模型列表及旧配置保留的回归测试，并更新中英文 AI 配置文档。
- 应用内版本号更新为 `v1.6.1`。

GPT-6 Astra 通过本机 Codex CLI 调用，需要所用 CLI 和账号支持该模型。本更新不包含任何个人配置、登录信息或监听记录。

安装包、便携包、Linux 包和 macOS 实验包会由 GitHub Actions 构建完成后自动上传到本 Release。

## English

This release adds GPT-6 Astra as an optional model for local Codex AI analysis without automatically switching existing users to it.

- Added `GPT-6 Astra` (`gpt-6-astra`) to the Codex model selector in AI settings.
- Added `low`, `medium`, `high`, `xhigh`, `max`, and `ultra` reasoning choices for Astra. Both new tasks and resumed conversations pass the selected model and effort to Codex CLI.
- Preserved existing AI provider, model, and reasoning settings. The Codex defaults remain `gpt-5.6-sol` with `high` reasoning; switching to Astra requires an explicit selection and save.
- Added regression coverage for model configuration, CLI arguments, UI model options, and existing configuration preservation, and updated the English and Chinese AI documentation.
- Updated the in-app version to `v1.6.1`.

GPT-6 Astra runs through the local Codex CLI and requires model support in the selected CLI and account. No personal configuration, sign-in data, or monitoring history is included in this release.

Installer, portable, Linux, and experimental macOS packages will be uploaded automatically by GitHub Actions after the release workflow finishes.
