# v1.6.0

## 中文

本版本增强股票看板与 AI 上下文联动，恢复 NGA 图片推送，并修正用户主页监听时的无效补全重试。

- AI 分析会从实际运行数据目录定位股票自选文件，缺失时自动初始化，并同步精简的持仓、自选和重点关注数据到 `context/positions.json`。
- 股票看板新增按名称、代码、价格、涨跌幅、成交额、持仓盈亏等字段排序，并保持刷新前后的图表选择。
- 增强港股展示：价格和金额使用 `HK$` 标识，A 股与港股持仓分别汇总，避免混合币种合计造成误导。
- 持仓识别统一为正数成本、正数持股或有效买入日期，排除零值、负数及无效数字。
- 适配 NGA 新图片附件地址：优先采用接口返回的 `_ATTACH_BASE_VIEW`，兼容旧域名，并在 HTTPS 下载受限时回退 HTTP，恢复飞书消息内的图片附件与可访问链接。
- 用户主页监听在补全论坛用户名时遇到“2048:版面关闭”会立即停止该次补全；正常从帖子内拉取回复仍保留原有重试机制。
- 新增 Windows 本地环境安装、测试、命令行和 WebUI 启动脚本；安装脚本会正确传递 Python、npm 和前端构建失败状态。
- 优化 WebUI 依赖与分包配置，固定兼容的 esbuild 版本，并拆分 React、ECharts 和图标依赖。
- 应用内版本号更新为 `v1.6.0`。

安装包、便携包、Linux 包和 macOS 实验包会由 GitHub Actions 构建完成后自动上传到本 Release。

## English

This release improves stock dashboard and AI context integration, restores NGA image delivery, and fixes wasteful enrichment retries while monitoring user profiles.

- AI analysis now resolves the stock watchlist from the runtime data directory, initializes it when missing, and syncs compact holdings, watchlist, and focus-watch data to `context/positions.json`.
- The stock dashboard can sort by name, code, price, change, turnover, position profit, and other fields while preserving chart selection across refreshes.
- Hong Kong stock presentation now uses `HK$`, and A-share and Hong Kong positions are summarized separately to avoid misleading mixed-currency totals.
- Holding detection is consistently limited to a positive cost, positive share count, or a valid buy date, excluding zero, negative, and invalid numeric values.
- NGA's new attachment host is supported through the API-provided `_ATTACH_BASE_VIEW`, legacy-host migration, and HTTP fallback when HTTPS downloads are rejected, restoring Feishu image attachments and reachable fallback links.
- User-profile monitoring now stops immediately on `2048: board closed` only during forum-name enrichment; normal reply collection from a thread keeps its existing retry behavior.
- Added Windows scripts for local setup, tests, CLI, and WebUI startup. Setup failures from Python, npm, or the frontend build are now propagated correctly.
- Improved WebUI dependency and chunk configuration by pinning a compatible esbuild version and splitting React, ECharts, and icon vendor bundles.
- Updated the in-app version to `v1.6.0`.

Installer, portable, Linux, and experimental macOS packages will be uploaded automatically by GitHub Actions after the release workflow finishes.
